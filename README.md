# Merge Shelter: 60 Seconds Survival

Hybrid-casual survival puzzle game.

## Vision
A 60–90 second survival puzzle where players merge resources on a compact board to build defenses, survive enemy waves, upgrade a shelter, unlock heroes, and progress through live events.

## Core Loop
Play board puzzle → survive wave → earn resources → upgrade shelter/heroes → unlock harder waves/events → return daily.

## Current Package
This repository starter contains:

- Technical design
