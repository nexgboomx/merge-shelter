# Branching Strategy

- `main`: release-ready only.
- `develop`: integration branch.
- `feature/*`: feature implementation.
- `fix/*`: bug fix.
- `release/*`: release candidate hardening.

## PR Rules
- Every PR must link an issue.
- Every PR must include test notes.
- Code PRs require QA checklist update when relevant.
- Release PR requires Project Manager, QA, and Code Agent sign-off.
