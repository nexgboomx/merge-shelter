# Production Roadmap

## Phase 0 — Repo & Pre-production
Goal: Make the project executable.

Tasks:
- Create repository and branch strategy.
- Add project docs, agent model, GDD, technical plan.
- Define MVP KPI gates.
- Create initial GitHub Issues.

Exit Criteria:
- Project board ready.
- Core systems scoped.
- Release checklist agreed.

## Phase 1 — Gameplay Prototype, 2–3 weeks
Goal: Prove the 60-second core loop.

Scope:
- 6x6 board.
- Drag/drop tile placement.
- Merge 3 same tiles.
- Enemy wave.
- Shelter HP.
- Win/fail/reward screen.
- 10 levels.

Exit Criteria:
- Player understands in <30 seconds.
- Round length 60–90 seconds.
- Core loop feels replayable without meta.

## Phase 2 — MVP+, 4–6 weeks
Goal: Add retention and monetization foundations.

Scope:
- 50 levels.
- Shelter upgrade.
- Hero skills.
- Daily reward.
- Rewarded ads and interstitial hooks.
- Starter pack and remove ads placeholders.
- Analytics schema.

Exit Criteria:
- D1 retention target: 35%+ in soft test.
- Rewarded opt-in target: 35%+.
- Crash-free users: 99%+.

## Phase 3 — Soft Launch, 6–10 weeks
Goal: Validate UA and LTV.

Scope:
- Remote Config.
- Economy tuning.
- 20+ creative variants.
- A/B testing.
- Store page.
- QA device coverage.

Exit Criteria:
- CPI/LTV signal supports scaling.
- D7 retention 12%+.
- Store rating 4.3+.
- Review-safe ad frequency.

## Phase 4 — Release Candidate
Goal: Ship stable version.

Scope:
- Compliance.
- Privacy policy.
- Final analytics validation.
- Ad/IAP production IDs.
- Release build signing.
- Store assets and screenshots.

Exit Criteria:
- All P0/P1 bugs closed.
- Release checklist signed.
- CI build green.
