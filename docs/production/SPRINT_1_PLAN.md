# Sprint 1 Plan

## Sprint Goal
Build a playable prototype of the 60-second core loop.

## Scope
- Board model
- Tile placement
- Merge 3 mechanic
- Basic enemy wave
- Shelter HP
- Win/fail flow
- Debug UI

## Agent Assignments

### Project Manager Agent
- Create issue board.
- Confirm acceptance criteria.
- Track daily blockers.

### Strategy Agent
- Define 5 ad hooks based on the prototype.
- Select first 3 markets for soft test.

### Game Design Agent
- Finalize tile rules.
- Define first 10 levels.
- Define enemy stats for level 1–10.

### Art & UX Agent
- Create board readability spec.
- Create placeholder tile icons.
- Define animation timing.

### Code Agent
- Implement BoardModel, MergeResolver, WaveManager, ShelterHealth.
- Add unit tests.
- Build Unity test scene.

### Content Agent
- Write tutorial text.
- Name first 10 levels.
- Create 10 short mission descriptions.

### QA Agent
- Test tutorial comprehension.
- Write smoke test checklist.
- Log P0/P1 issues.

### Data Agent
- Implement analytics interface.
- Define initial events.
- Validate funnel naming.
