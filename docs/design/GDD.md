# Game Design Document

## Title
Merge Shelter: 60 Seconds Survival

## Genre
Hybrid-casual survival puzzle with shelter meta.

## Player Fantasy
"I can save my tiny shelter from disaster by making fast, clever merge decisions."

## Core Board
- Grid: 6x6.
- Tile types: Wood, Metal, Food, Energy.
- Merge rule: 3 same type and same tier merge into 1 higher tier.
- Each round lasts 60–90 seconds.
- Enemy wave attacks after or during board decisions.

## Tile Functions
- Wood: creates/repairs wall.
- Metal: creates turret/weapon.
- Food: heals survivors/shelter.
- Energy: charges hero skill.

## First 10-Minute Experience
Minute 0–1:
- Tutorial: place 3 wood, create wall, survive first wave.

Minute 1–3:
- Add metal/turret.
- First satisfying enemy wave.

Minute 3–5:
- Unlock shelter upgrade.
- First rewarded ad opportunity: x2 reward.

Minute 5–10:
- First boss.
- First hero skill.
- Clear Day 1 milestone.

## Enemy Types
- Walker: baseline.
- Runner: fast, low HP.
- Tank: slow, high HP.
- Bomber: damages wall.
- Boss: telegraphed special attack.

## Disaster Modifiers
- Blizzard: freezes random cells.
- Blackout: disables turret for short time.
- Toxic fog: drains shelter HP unless food is merged.
- Earthquake: cracks board cells.
- Boss smash: destroys a row/column warning zone.

## Meta Systems
- Shelter upgrades.
- Hero collection.
- Research passives.
- Daily quests.
- Event missions.
- Battle pass.

## Design Pillars
1. Understand in 5 seconds.
2. Fun in 10 seconds.
3. Round complete in 90 seconds.
4. Every session grants progress.
5. Ads feel optional and rewarding.
6. Meta provides long-term goals.
