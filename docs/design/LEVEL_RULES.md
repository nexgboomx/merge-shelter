# Level Design Rules

## Difficulty Curve
- Levels 1–3: teach one mechanic per level.
- Levels 4–7: combine resource choices.
- Level 8: introduce runner.
- Level 10: first mini-boss.
- Level 15: first disaster modifier.
- Level 25: first build specialization choice.
- Level 50: MVP boss capstone.

## Round Structure
1. Setup phase: 5–10 seconds.
2. Merge phase: 30–60 seconds.
3. Wave phase: 20–30 seconds.
4. Reward phase: 5–10 seconds.

## Failure Rules
Failure should feel correctable:
- Not enough wall.
- Bad turret placement.
- Ignored energy skill.
- Failed to counter disaster.

Avoid:
- Sudden impossible spikes.
- Hidden enemy rules.
- Random failure without telegraph.
