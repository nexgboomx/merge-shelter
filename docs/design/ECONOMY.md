# Economy Design

## Currencies
- Coins: basic upgrade currency.
- Gems: premium currency.
- Parts: turret/shelter upgrade material.
- Event Tokens: temporary event currency.

## Sources
Coins:
- Level wins
- Daily rewards
- Idle expedition
- Rewarded ads

Gems:
- Achievements
- Battle pass
- IAP
- Event rank rewards

Parts:
- Boss stages
- Chests
- Event shop

## Sinks
Coins:
- Shelter upgrades
- Hero level up
- Research

Gems:
- Extra chest
- Speed up
- Premium hero draw
- Event retry

Parts:
- Turret upgrades
- Wall upgrades

## Early Pacing
Day 1:
- Fast upgrades every 2–5 minutes.
- No hard wall before level 10.
- First purchase offer after clear evidence of value.

Day 2–3:
- Introduce research.
- Introduce event tokens.
- Create first meaningful upgrade choice.

Day 7:
- Add Battle Pass pressure.
- Add weekly boss and clan teaser.

## Monetization Rules
- Never block tutorial with monetization.
- Rewarded ads only after player understands reward value.
- Interstitial after natural breaks, never during active board play.
- First purchase should feel like a bargain, not a requirement.
