# Release Checklist

## Build
- Version number updated.
- Android signing configured.
- iOS signing configured if applicable.
- CI build passes.
- No debug menus in production.
- Production ad/IAP IDs set.

## Compliance
- Privacy policy available.
- Terms available.
- Age rating questionnaire completed.
- Data safety form completed.
- ATT prompt flow prepared for iOS.

## Store
- App icon.
- Feature graphic.
- 5 screenshots.
- 1 promo video.
- Short description.
- Long description.
- Keywords.
- Support email.

## Product
- Tutorial tested.
- Level 1–50 playable.
- Daily reward works.
- Ads optional and capped.
- IAP restore works.
- Offline handling defined.

## Analytics
- Events validated.
- Crash reporting active.
- Remote Config active.
- Funnel dashboard prepared.

## Go/No-Go
- P0 bugs: 0.
- P1 bugs: 0.
- Crash-free: >99%.
- Store rating test group: 4.3+ target.
